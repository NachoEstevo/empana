# Empana

Una web chiquita para resolver una escena muy específica y muy argentina: estás con amigos, alguien abre el celu, cargan rápido qué empanadas quiere cada uno, reparten la cuenta sin pensar demasiado y, si la noche sigue, queda un anotador de truco a mano.

No nació como startup ni como side project eterno. Nació para ser útil.

## En una hora

Este proyecto fue hecho en aproximadamente una hora, con una regla simple: que en mobile se entienda todo al primer vistazo y que tocar la pantalla dé menos trabajo que mandar mensajes al grupo.

Por eso tiene tres cosas y no veinte:

- `Pedido`: sumar gustos por persona, copiar resumen y compartir link.
- `Split`: repartir la cuenta por cantidad de empanadas, con extras comunes.
- `Truco`: un anotador rápido, grande y sin vueltas.

## Idea

Hay proyectos que justifican arquitecturas enormes. Este no.

Acá la gracia era otra: tomar una situación cotidiana, resolverla bien para teléfono y hacerlo con suficiente cariño como para que, aunque sea un proyecto corto, no se sienta improvisado.
